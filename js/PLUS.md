# 追加教材の形式（js/plus/*.js）— 「超わかりやすい説明」＋「同じ型の演習 12 文」

各ファイルは 担当の単元だけを、次の形で登録する（ES5・ただの script）。
既存の data-c*.js は さわらない。アプリが読みこむときに 単元へ合体させる。

```js
window.LX = window.LX || { courses: [] };
window.LX.plus = window.LX.plus || {};
window.LX.plus["c1-u03"] = {
  core: {                       // 1 枚目「ひとことで言うと」
    ico: "🏹",                  // 絵文字 1 つ（イメージを表す）
    catch: "現在完了は「過去から今に刺さる矢」",   // 26 字以内。比喩・イメージで言い切る
    say: "過去のできごとが、今とつながっている。だから話の中心は「今」。",  // 64 字以内
    fig: { ... }               // 図（下の 5 種類のどれか。必須）
  },
  points: [                     // ちょうど 3 枚。今の points を「超わかりやすく」書き直す
    {
      h: "継続「ずっと〜している」",         // 18 字以内
      body: "...",                          // 70 字以内。中学生にもわかる言葉。たとえ話・コツ歓迎
      form: "have ＋ 過去分詞 ＋ for／since",  // 30 字以内。なければ ""
      ex: "I [have lived] in Osaka for ten years.",   // [ ] は 1 か所
      exja: "私は10年間大阪に住んでいる。",
      fig: { ... },                         // 任意（あると良い。3 枚中 1〜2 枚に付けるのが目安）
      ng: { bad: "I have lived in Osaka since ten years.",   // よくある まちがい（英文）
            good: "I have lived in Osaka for ten years.",    // 正しい英文
            why: "期間（10年間）は for、始まった時点は since" } // 40 字以内
    }
  ],
  drills: [                     // ちょうど 12 文。今ある 6 文と「同じ型」の 演習用例文
    { en: "She [has worked] here since 2020.", ja: "彼女は2020年からここで働いている。",
      alt: ["works", "worked", "is working"], tip: "since ＋ 始まった時点" }
  ]
};
```

## 図（fig）の 5 種類
1. **slots**（文の部品を 色分け）… 文型・修飾・語順に
   `{ t: "slots", parts: [["The news","S"],["made","V"],["me","O"],["happy","C"]], arc: [3, 2, "me の説明"] }`
   - parts: 2〜6 個。[英語(18字以内), 役割]。役割は S V O C M（修飾）か、4 字以内の日本語ラベル（例: "関係詞"）
   - arc（任意）: [どこから, どこへ, ラベル(10字以内)] … parts の番号（0 から）。矢印で「説明する・修飾する」関係を示す
2. **time**（時間の線）… 時制に
   `{ t: "time", marks: [ { from: -3, to: 0, label: "ずっと住んでいる" }, { at: -1, label: "去年" } ] }`
   - 目盛りは -4（過去）〜 0（今）〜 4（未来）。from/to は帯（to に矢印）、at は点。marks は 1〜3 個、label 12 字以内
3. **scale**（ものさし）… 確信度・程度・比較に
   `{ t: "scale", left: "たぶん…", right: "ぜったい", items: [["may", 30], ["probably", 70], ["must", 95]] }`
   - items 2〜5 個。[英語(14字以内), 0〜100 の位置]。left/right は 8 字以内
4. **flow**（流れ）… 文章の組み立て・論理展開に
   `{ t: "flow", steps: ["主張", "理由①", "具体例", "結論"] }`  steps 2〜5 個、各 8 字以内
5. **vs**（くらべる）… まぎらわしい 2 つの区別に
   `{ t: "vs", a: ["I have lost my key.", "今もない"], b: ["I lost my key.", "今は不明"] }`
   - a/b: [英文(30字以内), 説明(14字以内)]

## drills のルール（例文 sentences と同じ。いちばん大事）
- 4〜12 語。[ ] はちょうど 1 か所・1〜3 語。文末は . ? ! のどれか。文中に " と / は使わない（' は OK）。
- [ ] の中身は、その単元で練習する「型」の部分。今ある 6 文と同じ型で、単語・場面を変える（同じ英文の言いかえ・重複は不可）。
- alt はちょうど 3 つ。[ ] と置きかえると **はっきりまちがい** になるもの（口語で通じてしまうものは避ける）。正解と同じものは不可。大文字・小文字も合わせる。
- 高校生が教科書で見るような 自然で正しい英文。部活・学校・家族・旅行・SNS・環境など 身近な場面。
- 易→難の順。tip は 30 字以内。ja は 自然な日本語。

## わかりやすさのコツ
- 「ルールの暗記」より「なぜそうなるか」のイメージ（例：to 不定詞＝これから向かう矢印、動名詞＝もうやっている・ふだんやっている）。
- 日本人がまちがえやすい所を ng に（例：I'm agree ✕）。
- 専門用語は使ってよいが、すぐ やさしく言いかえる。
