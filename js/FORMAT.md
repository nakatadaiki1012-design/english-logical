# 教材データの形式（js/data-c1.js, data-c2.js, data-c3.js）

各ファイルはこの形で 1 コースを登録する（ES5 互換・ビルド不要のただの script）:

```js
window.LX = window.LX || { courses: [] };
LX.courses.push({
  id: "c1", name: "論理表現Ⅰ", short: "Ⅰ",
  desc: "基本の文法で、自分のことを正しく伝える",   // 30字以内
  units: [
    {
      id: "c1-u01",                 // コースid-u2けた
      title: "文の型（5文型）",       // 12字以内
      en: "Sentence Patterns",      // 英語の小見出し
      tag: "文法",                   // "文法" か "表現"
      goal: "動詞のあとに来る形で、文の意味を決められる", // 32字以内
      points: [   // ちょうど 3 枚。1 枚がスクロールなしで画面に入る量
        {
          h: "SVOC の C は O の説明",      // 18字以内
          body: "make や keep のあとに「O ＋ C」が来ると、「O を C の状態にする」という意味。C には形容詞や名詞が入る。", // 90字以内
          form: "S ＋ V ＋ O ＋ C",       // 型（30字以内）。なければ ""
          ex: "The news made me [happy].",   // 例文。[ ] はその項目で大事な所（1か所）
          exja: "その知らせで私はうれしくなった。"
        }
      ],
      sentences: [  // ちょうど 6 文。暗記用の基本例文（教科書に出てくるような自然な文）
        {
          en: "The news made me [happy].",   // 4〜12語。[ ] はちょうど1か所、1〜3語。文末は . ? ! のどれか
          ja: "その知らせで私はうれしくなった。",
          alt: ["happily", "happiness", "to be happy"], // [ ] に入れると「まちがい」になる選択肢 ちょうど3つ（まぎらわしいが明確に誤り。正解と同じものは不可）
          tip: "make ＋ O ＋ C「O を C にする」"          // 解説 30字以内
        }
      ],
      summary: ["make O C ＝ O を C にする", "...", "..."]  // ちょうど 3 行、各 28 字以内
    }
  ]
});
```

ルール
- 英文はネイティブが見て自然で、文法的に正しいこと。高校生向けの語彙。
- [ ] の中身と alt は、英文中の [ ] をそのまま置きかえて文として読めるもの（大文字・小文字も合わせる）。
- 例文の [ ] 以外に [ ] や / を使わない。文中の「"」は使わない（' はOK: I'm, don't など）。
- 日本語はやさしい言葉で。中学生でもわかる説明。
- 「表現」の単元は、使える言い回し（つなぎ言葉・意見の言い方など）を [ ] にする。
- 6 文は、易→難の順。最後の 1〜2 文は少し長めでよい（12語まで）。
