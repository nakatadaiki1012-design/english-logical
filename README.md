# 論理表現ラボ

論理表現Ⅰ・Ⅱ・Ⅲの **文法と表現を「覚えて、使える」ようにする** Webアプリです。
`index.html` をブラウザで開くだけで動きます（インストール不要）。見た目は「数学Aラボ」とそろえた方眼ノート風です。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/english-logical/

## どの画面も スクロールなし

スマホ（縦・横）・タブレット・パソコン・プロジェクターのどれでも、1 画面に 1 つのことだけを出します。
長い説明は ◀ ▶ でめくる形にしてあり、上下にスクロールする場面はありません。

## 理系の教科とのちがい：「わかる」のあと「体に入れる」

数学・物理・化学は「しくみがわかれば 解ける」ことが多いですが、英語は **わかっても 口から出てこない** ことがよくあります。
そこで 1 つの単元を、次の 7 ステップ ＋ 復習 で進めます。

| ステップ | すること | ねらい |
|---|---|---|
| 💡 ポイント | ✨ひとことで言うと（イメージ＋図）→ ポイント 3 枚（図つき）→ ⚠まちがえやすいところ → 📌まとめ | わかる |
| 🗣 音読 | 例文を聞いて、声に出して読む。✓ をおすたびに 英文が少しずつかくれて、3 回目は頭文字だけ | 声に出して覚える（音読 → 暗唱） |
| 🧩 並べかえ | 日本語を見て、英語のカードを正しい順にタップ | 語順を組み立てる |
| ✏️ 穴うめ | 大事な所（　）に入るものを 4 つからえらぶ | まぎらわしい形を見分ける |
| ⚡ 英作文 | 日本語を見て すぐ英語で言う → 答えを見て 自分で ○△✕ | 思い出す練習（いちばん記憶に残る） |
| 💪 演習 | **同じ型の 別の例文 36 文** から 毎回ちがう 12 問を 並べかえ・穴うめで。「もう 1 セット」で 別の問題に | 数をこなして 型を体に入れる |
| 🏁 テスト | 穴うめ 3 問 ＋ 並べかえ 2 問（例文と演習文から。初めて見る文も出る）。ヒントなし・1 回勝負、4 問以上で合格 | たしかめる |
| 🔁 復習 | 日をあけて もう一度 思い出す | 忘れる前に くり返す |

### 🔁 復習（間をあけて くり返す）

- 「⚡ 英作文」で ○△✕ をつけた文や、テストに合格した単元の文は、自動で「復習」に入ります。
- ○（言えた）が続くと、次に出るまでの間が **1 → 2 → 4 → 7 → 15 → 30 日** とのびていきます。✕ はその日のうちに もう一度出ます。
- 右上の 🔁 の数字が「今日の復習」の数です。3 回 ○ が続いた文は「定着した例文」として数えます。
- 復習がない日は「🎲 ランダムに 10 文 練習」ができます。

## 教材（全 36 単元・例文 216 文 ＋ 演習文 1,296 文 ＝ 1,512 文）

| コース | 単元 |
|---|---|
| 論理表現Ⅰ | 文の型（5文型）／時制／現在完了／助動詞／受動態／不定詞／動名詞／分詞／比較／関係代名詞／意見とその理由／情報を加える・例を挙げる |
| 論理表現Ⅱ | 過去完了・未来完了／助動詞＋完了形／仮定法過去・過去完了／仮定法のいろいろ／分詞構文／関係副詞と非制限用法／話法と時制の一致／強調・倒置／パラグラフの組み立て／賛成・反対を述べる／比べる・対比する／原因と結果 |
| 論理表現Ⅲ | 無生物主語／名詞構文／譲歩と条件／意見文の型／反論と再反論／データを説明する／問題と解決策／ディベートの表現／要約する／メールと手紙／ひかえめに言う／定義と具体例 |

各単元：
- **✨ ひとことで言うと**：文法を 1 つのイメージで言い切る（例：「現在完了は 過去から今に刺さる矢」）＋ 図
- **💡 ポイント 3 枚**：やさしい説明 ＋ 図 ＋ 例文
- **⚠ まちがえやすいところ**：「✕ まちがい → ○ 正しい」と その理由
- **📌 まとめ**
- **例文 6 文**（覚える用。音読・英作文・復習に使う）
- **演習文 36 文**（同じ型で 場面・単語を変えたもの。演習・テスト・ゲームに使う。演習は 36 文から 毎回ちがう 12 問）。そのうち 12 文は 10 語前後の 長めの文（ゲームの 🌌 長距離便 用）

図は 7 種類あります：文の部品の色分け（S 主語・V 動詞・O 目的語・C 補語・M 修飾）と「説明する」矢印、時間の線（過去・今・未来）、ものさし（確信度など）、流れ（文章の組み立て）、くらべる（まぎらわしい 2 つ）、**絵**（絵文字の場面＋矢印・吹き出しで 文法のイメージを見せる。例：受動態は ボール ← けられる ← Ken、仮定法は「もし鳥なら…」の吹き出し）、**くらべる棒**（比較・データ）。絵は イメージで覚えると効く所に 37 枚。

教材は `js/data-c1.js`（Ⅰ）・`js/data-c2.js`（Ⅱ）・`js/data-c3.js`（Ⅲ）に入っています。
書き方は `js/FORMAT.md` にあります。例文を差しかえたり、単元をふやしたりできます。
「ひとことで言うと」・図・まちがい・演習文は `js/plus/` にあり、書き方は `js/PLUS.md`、点検は `node js/plus/check.js js/plus/c1-a.js` です。長めの演習文は `js/more/`（点検は `node js/more/check.js js/more/c1-a.js`）。

## 📮 課題（先生がリンクを送る → 生徒が結果を送り返す）

1. **先生**：右上の「📮 課題」→「先生：課題をつくる」。単元にチェック、しめきり・ひとことを入れて「🔗 リンクをつくる」。リンクが自動でコピーされるので、LINE やメールで送ります。
2. **生徒**：リンクを開くと、ホームに「📮 課題 0/2 合格」が出て、課題の単元に 📮 の印がつきます。
3. **生徒**：「📮 課題」→ 名前を入れて「📤 結果を送る」。合格した単元・テストの点・かかった時間が文章になります（スマホなら そのまま LINE などで送れます）。

## 🎮 ごほうび・タイムアタック・クラス対戦

### 🪙 ごほうび（やるほど 段位が上がる）

- 正解するたびに **コイン** がたまります（正解 +10・英作文 ○ +5・音読 ✓ +1・テスト合格 +50、はじめての合格は +150・タイムアタックは 20 点で +1）。
- コインで **段位** が上がります：10級 → 9級 → … → 1級 → 初段 → 二段 → … → 五段 → **名人**。段位が上がると お祝いが出ます。
- 毎日続けると 🔥 **連続日数** がのびます。
- **バッジ 16 種類**（初合格・コース制覇・7日連続・30 コンボ・3,000 点・クラス対戦で表彰台 など）。右上の 🪙 をおすと 段位・バッジ・ベスト記録が見られます。

### 🚀 英文ロケット（ひとりで遊ぶ タイムアタック）

右上の 🎮 →「🚀 英文ロケット」。範囲（教科書 Ⅰ・Ⅱ・Ⅲ・全部、または「📚 単元をえらぶ」で 今日の単元だけ）をえらんで、3 つの コースから 1 つを押すと すぐ スタート。
並べかえと 穴うめは いつも まざって出ます（ミックス）。同じ範囲・同じコースなら 条件が そろうので、ベスト記録を そのまま くらべて 自慢できます。

| コース | 出る文 | 点数 | ミス |
|---|---|---|---|
| 🛩 ショート便 | 短い文（7 語まで） | ×1 | −1 秒 |
| 🚀 スタンダード便 | いろいろな長さ | ×1.3 | −1 秒 |
| 🌌 長距離便 | 長文だけ（9 語以上） | ×1.5 | −2 秒 |

長い文ほど 時間はかかるけれど、点数が 大きく のびます（寿司打の 高級コースのような しくみ）。

- **⛽ 燃料を入れて 打ち上げ**：正しいカードを押すたびに 燃料が入り、文が 1 つ完成するたびに ロケットが 上がる。長い文ほど 大きな燃料で たくさん上がる。
- **🗻 高度 ＝ 点数**：🗼東京タワー → 🏙スカイツリー → 🗻富士山 → ✈️飛行機の高さ → 🌤成層圏 → 🌌宇宙の入口 → 🛰宇宙ステーション → 🌕月 → 🔴火星 → 🟠木星 → 🪐土星 → 🔵天王星 → 🌀海王星 → 🛸太陽系の外 → 🌌天の川銀河の中心 → 🌀アンドロメダ銀河 → ✨宇宙の果て。きょりは km → 万 km → 億 km → 光年 と 単位が 変わる。問題の上の 空の帯に「いまの場所 → 次の めじるし」と 🚀 の位置が出て、上がるほど 空が 宇宙の色に なる。めじるしを こえると「🗻 富士山 突破！」。正解を続けるほど 長い文が 出てくる。
- **🌏 背景の景色**：問題のカードの うしろで 景色が 足もとへ 流れていく。発射台と 街 → 地面に 建つ 赤白の 東京タワー・スカイツリーの 横を 上って てっぺんを 追いこす → 地平線から そびえる 雪の 富士山（遠いので ゆっくり 流れる）→ 雲の層を つきぬけ（一瞬 白く かすむ）、飛行機雲を ひく 旅客機と すれちがう → 空が 暗くなって 青く光る 地球の ふちと 星 → 宇宙ステーション → クレーターの 月 → 火星 → しまもようと 大赤斑の 木星 → 輪のある 土星 → 天王星 → 海王星 → 探査機と 小さくなった 太陽 → 天の川 → アンドロメダ銀河 → 銀河だらけの 宇宙の果て。
  - カメラは「ばね」で 高度を 追うので、正解のたびに グッと加速して なめらかに 落ち着く。景色は 奥行きごとに 速さが ちがい、コンボ・ブーストで 雲や 星が 速く流れる。
  - 右下の ロケットは 白い機体と 二重の 炎。大気の中では けむりを ひき、宇宙では 炎が 青白く 広がる。ブースト中は 速さの線と 小さな ゆれ。
  - 宇宙に出ると カードは 夜の色（文字は 白）に。文字には ふちが あり、答えの カードは 透けないので 読みやすいまま。
  - 処理落ち対策：景色の絵は 最初に 1 回だけ 描いて 貼るだけ。重い端末では 自動で 背景の 細かさを 下げ、1 秒 30 回に 切りかえる。見ていない時は 止まる。端末で「動きを減らす」設定にしていると 景色は 動かない。
- **🔥 ブースト**：正解のたびに カードから 火花が 飛ぶ（コンボが続くほど 多い）。正解 20 タップで メーターが満タンになり **🚀 BOOST!!**（ミスすると メーターが 少し へる）（7 秒間 点数 ×2、画面の下から 炎、星が 流れる）。
- **点数の倍率**：コンボ 10 で ×1.5、25 で ×2、50 で ×3、100 で ×4（ブースト中は さらに ×2）。コンボ 5 で 小さく、10・25・50・100 で 大きく「COMBO!」。
- **⛽ 燃料（時間）**：60 秒分から スタート。コンボが続いている時に 文を完成させると 燃料が ふえる（並べかえ +1／+2／+3 秒、穴うめ +0.4／+0.8／+1.2 秒）。ミスは コンボが切れて −1 秒。
  40 秒をすぎると 空気がうすくなって 燃料の減りが だんだん速くなる（⏩ 最大 ×3）ので、どんなに上手でも 永遠には 続かない。

  | 腕前 | だいたい 続く時間 |
  |---|---|
  | はじめて | 約 1 分 |
  | ふつう | 約 1 分 15 秒 |
  | 上手 | 約 1 分 20 秒〜 |
  | 達人 | 約 2 分 |
  | ミスなし 最速 | 約 3 分 20 秒（ここで必ず 終わる） |
- **結果**：「🛰 宇宙ステーション（412 km）まで 到達！」と 通りすぎた めじるし・点数・完成した文の数・何分 続いたか・「〇語を組み立てた ≒ 英検 2 級のライティング 1 本分」。「あと 3,733 点で 🌕 月」のように 次の めじるしまでの 点数も 出る。「📣 自慢する」で 結果の文章をコピー。範囲 × コースごとに ベスト記録。
- 出題は えらんだ範囲の 例文と演習文から（1 単元でも 42 文、Ⅰ まるごとなら 500 文以上）。単元を しぼって 長文が 足りないときは、長距離便でも 短めの文が まざります。

クラス対戦は 全員そろって 終わるように、時間は 先生がえらんだ 長さで 固定です（火花・ブースト・倍率・空の帯は 同じ）。

### 🔊 効果音

タップ・正解・ミス・コンボ・カウントダウン・ファンファーレなどの効果音が鳴ります（音声ファイルは使わず、その場で作っています）。
⚙ 設定の「効果音」で オン／オフ できます。授業中に生徒のスマホの音がうるさいときは オフにしてもらってください（先生のプロジェクターの音だけでも 盛り上がります）。

### 🏆 クラス対戦（リアルタイム）

1. **先生**：🎮 →「🚀 ロケット対戦の 部屋」。4 けたの **部屋番号** と **QR コード** が出ます（プロジェクターに映す）。
   「⚙ 出題の設定（時間・単元・コース・映す人数）」で 次の 5 つを えらびます（スマホ・タブレットからでも OK）。
   | 設定 | えらべるもの |
   |---|---|
   | ⏱ 時間 | 30 秒・1 分・1 分半・2 分・3 分・5 分 |
   | 📚 範囲 | **今日の単元をえらぶ**（1 単元でも いくつでも、コースをまたいでも OK）／コース全部（Ⅰ・Ⅱ・Ⅲ・全） |
   | 🚀 コース | 🛩 ショート便・🚀 スタンダード便・🌌 長距離便（並べかえと 穴うめは いつも ミックス） |
   | 📖 出す文 | 例文＋演習文／例文だけ（覚えた文）／演習文だけ（初めて見る文） |
   | 🏆 映す人数 | 大画面の ランキングに 出す 人数：上位 3 人・5 人・10 人（はじめは これ）・全員。下の人は「…ほか 〇 人（順位は 自分の 画面で）」とまとめて表示 |
   えらんだ設定は 先生の画面に 1 行で出ます。設定は 回戦ごとに 変えられます。
2. **生徒**：QR を読みとる か、🎮 → 部屋番号とニックネームを入れて「参加する」。先生の画面に 名前が 次々ならびます。
3. **先生**：「▶ スタート」。全員の画面で 同時に 3・2・1 → GO!。先生の画面のランキングが **リアルタイムで動きます**。順位が入れかわると 行がすべって動き、1 位が変わると「👑 トップ交代！」。🔥 はコンボ中。生徒の画面には **いまの自分の順位** が出ます（大画面に 映らない 順位でも、自分の画面では いつも わかる）。
4. 時間が来ると「そこまで！」→ **表彰式**：ドラムロール → 3 位 → 2 位 → 暗転して スポットライト → **1 位が登場**（👑 が落ちてきて、ファンファーレ・紙吹雪・点数のカウントアップ）。「🎉 表彰式をもう一度」で 何度でも流せます。
   生徒の画面も、1 位は「👑 優勝！」と紙吹雪、2・3 位はメダル。全員に「〇 位 / 〇 人」と 自分の点数が出て、上位の表の下に 自分の行も ならびます。
5. 「▶ 第2回戦 スタート」で 何回でも。「🏆 ハイスコア」タブで その部屋の いちばん良い記録のランキング。
6. 終わったら「部屋を閉じる」（ランキングも消えます）。

40 人でも ランキングは 1 画面に収まります（入りきらないときは「…ほか n 人」）。

### 🎯 クイズ大会（カフートのような 先生ペースの 4 択）

🎮 →「🎯 クイズ大会の 部屋」（または 部屋の「⚙ 出題の設定」で **🎮 遊び方 → 🎯 クイズ大会**）で、1 問ずつ みんなで 答える クイズになります（部屋番号・QR・参加のしかたは クラス対戦と同じ）。

| 設定 | えらべるもの |
|---|---|
| ❓ 問題数 | 5・10・15・20 問 |
| ⏱ 1 問の 時間 | 10・20・30 秒 |
| 📚 範囲・📖 出す文・🏆 映す人数 | クラス対戦と 同じ |

1. **先生**：「▶ クイズ スタート」。大画面に 問題が出て、3 秒後に 4 色の 答え（▲ 赤・◆ 青・● 黄・■ 緑）が 開きます。右上に 残り秒数、「回答 12 / 30」と 答えた人数。
2. **生徒**：手元に 同じ 4 色の 大きな ボタン。早く 正解するほど 点が高い（最大 1,000 点）。連続正解で 🔥 ボーナス（+100〜+500）。パソコンなら 1〜4 キーでも 答えられます。
3. 時間切れ か 全員 答えると 自動で **答え合わせ**：正解に ✓、どれを 何人が えらんだかの グラフ、💡 なぜその答えか。生徒の 手元には「⭕ 正解！ +870 点 🔥3 連続」「いま 5 位 / 30 人」。
   「🔊 正しい英文を 聞く」で 読み上げも できます。
4. **先生**：「ランキング ▶」→ 上位の ランキング（映す人数で しぼれる）→「▶ 次の問題」。最後は「🏆 結果発表 ▶」で 表彰式（ドラムロール → 3 位 → 2 位 → 1 位）。
- 問題は 2 種類：**穴うめ**（英文の（　）に 入るもの）と **正しい英文は どれ？**（日本語を見て 4 つの 英文から えらぶ）。
- 結果発表の「📊 問題ごとの 正答率」で、正答率の 低い 問題（赤）が わかる → 次の授業の 復習に。「📋 結果をコピー」で 順位・名前・点数を Excel や スプレッドシートに 貼れます。生徒の 画面には「📝 まちがえた 問題」と 正しい 英文が 出ます。
- 早く しめきりたいときは「⏭ しめきる」。生徒が 読みこみ直しても 点数は つづきから。

### クラス対戦の準備（先生が 最初に 1 回だけ・無料）

クラス全員の点数を 1 か所に集めるために、Google の無料データベース **Firebase Realtime Database** を使います。

1. https://console.firebase.google.com を開いて、Google アカウントでログイン
2. 「プロジェクトを作成」→ 名前（例：`logic-class`）を入れて進む（Google アナリティクスは オフでよい）
3. 左のメニュー「構築」→「**Realtime Database**」→「データベースを作成」
   - 場所：**シンガポール（asia-southeast1）** など
   - 「**ロックモードで開始**」をえらんで「有効にする」
4. 「**ルール**」タブを開き、中身を ぜんぶ 下のものに置きかえて「公開」
   ```json
   {
     "rules": {
       "rooms": {
         "$code": {
           ".read": true,
           ".write": true
         }
       }
     }
   }
   ```
5. 「データ」タブの上に出ている URL（`https://〇〇-default-rtdb.〇〇.firebasedatabase.app`）をコピー
6. アプリの右上 ⚙ →「クラス対戦のデータベース」に はりつけて「保存して接続テスト」→「✅ つながりました」と出れば OK

- 生徒は 先生の部屋の **QR・リンク** から入れば、設定はいりません（リンクに URL が入っています）。
